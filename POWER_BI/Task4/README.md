## 📌 Objective
Build a dashboard that analyzes customer purchasing behavior and sales trends to improve business growth.

---

## 📂 Dataset

| Property | Detail |
|---|---|
| File | `Task4_Customer_Analytics.pbix` |
| Data Table | `CustomerData` |
| Fields | Customer ID, Customer Name, Age, Age Group, Gender, Region, Product Category, Purchase Amount, Purchase Date |
| Missing Values | Cleaned during Power Query import |

---

## ⚙️ Key Requirements Implemented
- Analyzed customer demographics and purchasing patterns
- Identified top customers based on revenue generation
- Displayed repeat customer rates and sales distribution
- Created visualizations for customer segmentation
- Added dynamic filters for region, age group, and product category

## 🚀 How to Run
1. Install **Power BI Desktop** (free from Microsoft).
2. Open `Task4_Customer_Analytics.pbix`.
3. Use **Refresh** (Home tab) to reload data if connected to a live source.
4. Interact with the Age Group and Gender slicers to explore customer purchasing behavior.

---

## 💡 Features
- KPI-first layout with customer count, purchase amount, and average age cards
- Product category breakdown of purchase amount
- Regional distribution of customer base via donut chart
- Age Group and Gender-based segmentation for targeted insights

---

## 📈 Key Results
- Customer purchases are led by Apparel and Electronics categories
- East and West regions hold the largest shares of the customer base
- Average customer age of ~44 suggests a predominantly middle-aged buyer segment
- Dashboard enables quick identification of high-value customer segments by region, age, and gender

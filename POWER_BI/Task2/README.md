## 📌 Objective
Create a Power BI dashboard that monitors employee performance and workforce productivity to support HR decision-making.

---

## 📂 Dataset

| Property | Detail |
|---|---|
| File | `Task2_Employee_Performance.pbix` |
| Data Table | `EmployeeData` |
| Fields | Employee ID, Employee Name, Department, Designation, Attendance Rate, Days Present, Performance Score, Reporting Period, Total Working Days |
| Missing Values | Cleaned during Power Query import |

---

## ⚙️ Key Requirements Implemented
- Imported employee attendance and performance datasets
- Visualized employee productivity, attendance, and department-wise performance
- Displayed KPIs such as Total Employees, Attendance Rate, and Performance Score
- Created interactive charts for department comparisons
- Added slicers for department, designation, and reporting period

## 🚀 How to Run
1. Install **Power BI Desktop** (free from Microsoft).
2. Open `Task2_Employee_Performance.pbix`.
3. Use **Refresh** (Home tab) to reload data if connected to a live source.
4. Interact with the Department and Designation slicers to explore attendance and performance trends.

---

## 💡 Features
- KPI-first layout with headcount, attendance, and performance cards
- Quarter-over-quarter (Q1–Q3 2025) performance comparison by department
- Department-wise headcount breakdown via donut chart
- Drill-through enabled for deeper HR analysis

---

## 📈 Key Results
- HR maintains the largest headcount share, followed by Sales, Marketing, and Finance
- Average performance scores stay fairly consistent across Q1–Q3 2025 within each department, indicating stable productivity
- Attendance rate of ~89% across the workforce highlights generally strong employee engagement
- Dashboard enables quick spotting of departments needing performance or attendance support

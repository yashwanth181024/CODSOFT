## 📌 Objective

---

## ⚙️ Key Requirements Implemented
- Imported student marks and attendance datasets
- Analyzed subject-wise and class-wise performance
- Displayed attendance percentage and examination results
- Created charts showing topper lists and grade distributions
- Added filters for classes, subjects, and academic sessions

---

## 🔧 Dashboard Breakdown

### KPI Cards
| Metric | Description |
|---|---|
| Total Students | Count of Student ID |
| Average Attendance % | Average of Attendance % |
| Average Marks | Average of Marks |

### Visuals
- **Bar/Column Chart** — Subject-wise and Class-wise average performance
- **Table/Chart** — Topper list (top-scoring students)
- **Donut/Pie Chart** — Grade distribution (A, B, C, etc.)

### Slicers / Filters
- Class
- Subject
- Academic Session

## 🚀 How to Run
1. Install **Power BI Desktop** (free from Microsoft).
2. Open `Task3_Student_Performance.pbix`.
3. Use **Refresh** (Home tab) to reload data if connected to a live source.
4. Interact with the Class, Subject, and Academic Session slicers to explore performance and attendance trends.

---

## 💡 Features
- KPI-first layout with student count, attendance, and marks cards
- Subject-wise and class-wise performance comparison
- Topper list highlighting the highest-performing students
- Grade distribution visualization for quick academic health checks

---

## 📈 Key Results
- Identifies subjects and classes with the strongest and weakest average performance
- Highlights attendance trends that may correlate with academic results
- Surfaces top-performing students per class/subject for recognition
- Supports data-driven decisions on academic support and intervention

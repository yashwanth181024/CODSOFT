## 📌 Objective
Develop an interactive Power BI dashboard to analyze sales performance across different products, regions, and time periods. The dashboard helps businesses monitor revenue trends and make informed decisions.

---

## 📂 Dataset

| Property | Detail |
|---|---|
| File | `Task1_Sales_Performance.pbix` |
| Data Table | `SalesData` |
| Fields | Order ID, Order Date, Product, Category, Region, Sales Rep, Sales, Profit, Unit Price, Units Sold |
| Missing Values | Cleaned during Power Query import |

---

## ⚙️ Key Requirements Implemented
- Imported and cleaned sales data from Excel/CSV files
- Created interactive charts to visualize sales, profit, and order quantities
- Analyzed monthly, quarterly, and yearly sales performance (Order Date hierarchy)
- Added slicers and filters for products, regions, and sales representatives
- Designed KPI cards to display Total Sales, Profit, and Units Sold

---

### Slicers / Filters
- Region (Central, East, North, South, West)
- Category (Accessories, Electronics, Furniture, Stationery)

## 🚀 How to Run
1. Install **Power BI Desktop** (free from Microsoft).
2. Open `Task1_Sales_Performance.pbix`.
3. Use **Refresh** (Home tab) to reload data if connected to a live source.
4. Interact with the Region and Category slicers to explore sales, profit, and units sold.

---

## 💡 Features
- KPI-first layout with cards for Sales, Profit, and Units Sold
- Cross-filtering between the bar chart and stacked bar chart
- Region and Category level breakdown of performance
- Clean, business-ready visual design

---

## 📈 Key Results
- Laptop and Smartphone emerged as the top revenue and profit-driving products
- Sales are distributed fairly evenly across regions within each product category
- Dashboard enables quick identification of top- and bottom-performing products by region
